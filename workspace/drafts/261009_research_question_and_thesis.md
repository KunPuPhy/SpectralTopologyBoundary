# 研究问题与核心命题（2026-10-09 定稿；2026-10-15 命题改三层版）

**研究问题**

> 谱学探针（以 ARPES 谱函数与冷原子 Bragg 谱为代表），原则上能把能带拓扑确定到什么程度？测量拓扑性质是否完备

**原待回答的问题（2026-10-15 已答，答案即命题第一层的根据）**

> Bragg 谱与 ARPES 谱函数的共性是什么，可否有个统称？

**答案**：共性是同一条公式——两类信号都是"参考态 × 带本征态"的投影重叠（交叠的模方）
$w=\mathrm{Tr}\,P_{\hat a}\,P_\pm(k)=\tfrac12(1\pm\cos\ \text{夹角})$：SPSF 的参考 $\hat a=\hat z$ 被晶格钉死，Bragg 的 $\hat a=\hat{\mathbf d}(k_0)$ 随初态可动。由此两层共同命运：(i) 强度只见夹角的余弦（偶函数）⟹ 镜像轨迹对数据逐项全同而 $W\to-W$ ⟹ 符号结构性不可读，对整类成立；(ii) $|W|$ 的可操作计数都以 $\psi$ 单调为前提，非单调轨迹骗两者。
**统称（2026-10-15 修订：不造新类名，用结构属性定义类）**：学界无现成统称，论文不把造词当共识术语用。做法：一句话定义类——**信号 = 参考态与 Bloch 本征态交叠的模方（= 带投影算符的期望值，布居型数据）**；两种谱是该类的两个标准实例（SPSF 参考被晶格钉死、Bragg 参考随凝聚点可动）；类在 $\delta=0$ 下对任意参考与组合封闭，no-go 对整类成立（分离定理）。语汇支点（学界现成）：E-R 自己的 **first-order coherence**（一阶相干，其 Eq. (25)）——"布居 vs 相干"二分；修复句接此语汇。**"偶角 / even-angle" 只作机制名**（论文主选标题的机制词，机制由发现者命名），不作类名。

**核心命题（三层：共性 → 特性 → 限定；推导链见 `261009_derivation_cos_to_winding.md`，数值核验 c1–c12 全过）**

**共性——一维本身就有完备性问题，两类探针共有，高维避免不了**

1. **符号 no-go**：强度 = 交叠的模方，模方丢相位，而绕数符号恰住在被丢的相位里。镜像对 $(d_x,d_y,d_z)$ vs $(d_x,-d_y,d_z)$ 是两个真实物理系统（复共轭实现，能谱全同、带序不变），一切 $\delta=0$ 强度逐项全同而 $W\to-W$——存在性论证而非难度论证：任意探针、参考、组合、后处理均不可豁免。
2. **$|W|$ 非免费**：像集全覆盖（处处满转移）只是 $W\neq0$ 的**必要**条件（双程 DC：$W=0$ 而 $W_{\max}(k_0)\equiv1$）；簇数计数要求 $\psi$ 单调——非单调轨迹（双程、回折、折叠）制造两类探针共有的假阳性。
3. **一维问题通向高维**：高维探测沿动量线切片仍是一维读数，镜像偶性逐切片保留；Estake–Roy 的 2D 假阳性（$d_y=\sin^2 k_y$）正是 1D 偶化机制的二维版，Chern 符号同样结构性不可读。前人已提的"高维少一维"新问题叠加其上，**不取代**一维问题。

**特性——Bragg 优于 ARPES：参考可动，$\phi$ 有唯一入口**

1. SPSF 强度 $\tfrac12(1\pm\cos\theta_k)$ 不含 $\phi$（SSH 构型 $\rho=0$ 严格 $\tfrac12$ 全盲）；Bragg 强度含 $\cos\Delta\varphi$（通道增益 $\sin\theta_{k_0}\sin\theta_k$）——方位差进入强度仅此一门。
2. **对跖判据族**：满转移 $\iff$ 对跖在像内（恒等式）；$W\neq0\Rightarrow W_{\max}(k_0)\equiv1$（逆否一票否决）；偏轴参考压折叠轨迹于可证上界 $\tfrac{1+\sqrt{1-\hat d_{0\perp}^2}}{2}<1$。SPSF 的假阳性可被一般参考的 Bragg 揭穿（T vs R：$1.000$ vs $0.500$）。
3. **工程性优势**：总密度探针无需子格分辨（无 $\mathrm{Tr}\,P_\pm=1$ 相消）、手性 SSH 不失明、同谱比值 $R=\tan^2(\Delta\psi/2)$ 自归一（免绝对校准）。
4. **族级充分性**：扫 $k_0$ 的完整成对强度 = Gram 矩阵 ⟹ 像集定到 $O(3)$（旋转+反射）⟹ $|W|$ 原则上可读且免单调先验——SPSF 的轴被晶格钉死，结构上无此自由度。

**限定——Bragg 仍未解决什么**

1. **$k_0$ 被基态钉死**：真实实验 $k_0=$ 下带底（凝聚点），非自由旋钮。底落极点时（Kitaev 型标准族 $d_z$ 幅度主导时底在 $\hat{\mathbf d}(k_0)=\pm\hat z$；QWZ $u<0$ 的 $(\pi,\pi)$）Bragg 逐点退化为 SPSF（c7：$5.6\times10^{-17}$），继承其全部假阳性且换参考逃生门关闭——**天然凝聚点恰是最坏测点**（可检验预言）。
2. **判据层仍需先验**：$W_{\max}$ 泛函（即使扫遍 $k_0$）只是必要条件（DC）；$|W|$ 计数依赖 $\psi$ 单调，而单参考数据只见 $\cos\Delta\psi$、其两支提升含回折解——单调性是模型先验，不能由单参考数据自证；免先验须付族数据成本（移动凝聚）。
3. **δ 弦边界**：$\delta\neq0$ 形状因子是强度层内唯一重新注入手征的通道（$w\propto\cos[(W-\delta)(k-k_0)]$，$\delta$ 扫描 V 形顶点含符号），但 $\delta$ 为设计期固定的几何参数；自然对称晶格 $\delta=a/2$ 恰为擦除值（$\mathbb Z_2$ 对 $(W,W\oplus1)$ 数据全同）；极点参考处弦严格惰性。**论文处理**：正文全文 $\delta=0$、弦定理进 SM；但 §III 必须保留类定义句（no-go 范围 = 对镜像盲的耦合，即 $\delta=0$）与一句 remark（$\delta\neq0$ 是唯一逃生通道及其三条限制），否则命题 (iii) "no combination of intensity data" 越界成假命题——彻底删 $\delta$ 等于把类级 no-go 降格为两个案例。
4. **收口**：缺失的符号是相位一比特。回路相位（Zak）$e^{i\pi W}$ 只给 $W\bmod2$——它自身是镜像偶的（$e^{i\pi(\pm1)}=-1$），独特价值在与 $k_0$ 无关、极点照常工作；符号比特住在奇宇称 sector 的相位里（非对角谱函数幅角 $\propto\mathrm{sign}(\sin\psi)$；2D：Berry 曲率/Chern）。**修复必然超出强度型探针——no-go 的范围 = $\delta=0$ 镜像对称探针类，边界即此。**

**§II 两个公式与一个机制（~1 页）**
- 主题内容：一句话定义强度探针类（信号 = 参考态与带本征态交叠的模方），写出 SPSF 与 Bragg 两个强度公式，指出两者都只是夹角的余弦。
- 需要画的图：F1 示意图——Bloch 球上两种夹角（钉死的晶格轴 vs 可动的初态参考）、含轴镜像面、对跖点与方位通道。
- 要说明的结论：一切强度只见纬度与夹角余弦，方位角的带符号信息从定义起就不在场——两类谱同属一类。

**§III 机制与三条推论（~1.5 页）**
- 主题内容：把轨迹关于被分辨轴作镜面变形（横向分量反号），一切强度不变而绕数翻转或归零；推论三条——符号 no-go、极点退化、偏轴上界。

**§IV 假阳性是一个家族（~1.5 页）**
- 主题内容：用同一机制读五个案例——Kitaev 正参照、半平面折叠最小例、E-R 自己的 2D 反例、全参数平庸的 cos k 变体、以及 Bragg 自己的反例（双程）。
- 需要画的图：F4 一维家族总图（SSH 全盲 / Kitaev 真 / cos k 假→揭穿 / 双程假，每行 SPSF 与 Bragg 双面板）；F5 二维桥（QWZ 真假对：SPSF 图案相同、极点同骗、一般参考分离，附两条可证上界曲线）。
- 要说明的结论：假阳性属于一个家族——SPSF 的假阳性可被可动参考的 Bragg 揭穿，但 Bragg 自己也有（双程），像集全覆盖不等于绕数非零。

**§V 修复是一比特相位（~0.75 页）**

- 需要画的图：F6 相位修复（回路相位给 $W\bmod 2$、与参考无关、极点照常工作，非手性给非量子化 Zak，符号比特在相干里）。
- 要说明的结论：修复必然超出强度型探针——no-go 的边界即 $\delta=0$ 镜像对称类，符号比特住在相干里。
