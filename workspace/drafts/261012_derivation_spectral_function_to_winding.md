## 第一部分　从谱函数的定义到二能级一般形式

### 1.1 谱函数的定义

对象是一条链（或高维系统沿某方向切出的一条线）上的两条能带，单体哈密顿量 H(k)：

- k：一维动量，取值布里渊区（BZ，动量空间的原胞）k ∈ [−π, π]；晶格常数取 1（恢复记号时 k → ka，a 为晶格常数）。
- H(k)：2×2 厄米矩阵（两条带），作用在二维内态空间上。
- α ∈ {A, B}：内态指标——被实验分辨的那个自由度：子格（SSH 类）、粒子–空穴（Kitaev 类的 Nambu 基）、自旋等。取基矢 |A⟩ = (1,0)^T、|B⟩ = (0,1)^T（列矢量写法；T 表示转置）。

推迟格林函数（"推迟" = 只含因果响应；物理：在 k、ω 处找到一个单粒子态的概率幅）：

$$G^R(k,\omega) \;=\; \big[\,\omega + i0^+ - H(k)\,\big]^{-1}$$

- ω：能量变量（探测给出的能量）；
- i：虚数单位；0⁺：无穷小正数（保证衰减边界条件，把谱线压成尖峰）；
- [·]^{-1}：2×2 矩阵求逆。

谱函数（强度型实验的直接对象；ARPES/STS 测对角元 α = β）：

$$A_{\alpha\beta}(k,\omega) \;\equiv\; -2\,\mathrm{Im}\,G^R_{\alpha\beta}(k,\omega)$$

- Im：取虚部；G^R_{αβ}：G^R 的 αβ 矩阵元。

**谱表示**（把逆矩阵按本征态展开：设 H(k)|u_n(k)⟩ = E_n(k)|u_n(k)⟩，其中 |u_n⟩ 是第 n 条带的本征态、E_n 是其能量；则 (ω+i0⁺−H)^{-1} = Σ_n |u_n⟩⟨u_n| / (ω−E_n+i0⁺)，再用 Im 1/(x+i0⁺) = −πδ(x)，其中 δ(x) 是 Dirac δ 函数——把谱线钉在带能量上）：

$$A_{\alpha\alpha}(k,\omega) \;=\; 2\pi\sum_n \big|\langle\alpha|u_n(k)\rangle\big|^2\,\delta\big(\omega - E_n(k)\big)$$

- ⟨α|u_n⟩：内态 |α⟩ 与本征态 |u_n⟩ 的交叠（一个复数）；|·|²：模方；2π：δ 峰面积与权重相配的常数。

**物理含义（全文出发点）**：谱函数 = "在动量 k、内态 α 上找到能量 ω 的粒子"的概率密度；每条带的谱线强度 = 内态 α 在该带本征态里所占的份额：

$$w^{(n)}_\alpha(k) \;\equiv\; \big|\langle\alpha|u_n(k)\rangle\big|^2 \qquad\text{一切强度都是交叠的模方。}$$

### 1.2 二能级系统：Bloch 矢量与球坐标

任何 2×2 厄米矩阵都可展开为

$$H(k) \;=\; d_0(k)\,\mathbb 1 \;+\; d_x(k)\,\sigma_x + d_y(k)\,\sigma_y + d_z(k)\,\sigma_z$$

- σ_x, σ_y, σ_z：三个 Pauli 矩阵；𝟙：2×2 单位阵；
- d_0, d_x, d_y, d_z：k 的实周期函数；
- d ≡ (d_x, d_y, d_z)：三维实矢量（Bloch 矢量）。

d_0𝟙 只把两条能级整体平移、**不动本征态**（单位阵乘任何态都只差一个数），故强度与它无关——以下取 d_0 = 0，需要时随时加回。

**能隙条件**：|d(k)| > 0 对一切 k（|d|：矢量长度）。|d| = 0 处两带相碰、本征态无定义——这是拓扑唯一可变的窗口（§2.1 用到）。

**本征值**：E_±(k) = ±|d(k)|（+ 上带、− 下带）。[由 Pauli 恒等式 (d·σ)² = |d|²𝟙：作用在本征态上给出 E² = |d|²。]

**Bloch 球**：单位矢量 d̂(k) ≡ d(k)/|d(k)| 是单位球面（Bloch 球）上的一个点。k 扫过 BZ 一圈，d̂(k) 在球面上画出一条**闭曲线**（记作轨迹 C；k = ±π 是同一个点，故首尾相接）。**能谱之外，系统的全部信息就是这条曲线。**

**球坐标**（把被分辨内态 |A⟩ 的方向定为 z 轴 / 北极）：

- θ_k ∈ [0, π]：**极角**——d̂(k) 与 z 轴的夹角，cos θ_k = d̂_z(k)（d̂ 的 z 分量）。θ = 0 北极，θ = π/2 赤道。
- φ_k：**方位角**——d̂(k) 绕 z 轴的转角，φ_k = arg(d̂_x(k) + i d̂_y(k))（arg：复数的辐角）。**绕数住在 φ 里（§2.1）**。

显式本征矢（供 §1.3 代入；逐项乘 H 可验证本征方程）：

$$|u_+(k)\rangle = \begin{pmatrix}\cos(\theta_k/2)\\ e^{i\phi_k}\sin(\theta_k/2)\end{pmatrix},\qquad |u_-(k)\rangle = \begin{pmatrix}-e^{-i\phi_k}\sin(\theta_k/2)\\ \cos(\theta_k/2)\end{pmatrix}$$

**赝自旋图像（全篇物理内核）**：把 σ 读作自旋算符，则 |u_±(k)⟩ 是"自旋指向 ±d̂(k)"的态——**上/下带本征态的赝自旋沿 ±d̂(k)**。于是：谱函数强度问"赝自旋与**钉死的 z 轴**夹角多少"（§1.3）；Bragg 强度问"轨迹上**两个赝自旋互相**夹角多少"（§1.4）。

### 1.3 推导：谱函数强度 = ½(1 ± cos θ)

要算的量（§1.1 的权重，内态取 α = A；上标 A 标记"子格分辨谱函数"一类强度）：

$$w^A_\pm(k) \;\equiv\; \big|\langle A|u_\pm(k)\rangle\big|^2$$

**推导**（本征矢代入 |A⟩ = (1,0)^T，取第一个分量的模方）：

$$w^A_+(k) = \cos^2\frac{\theta_k}{2},\qquad w^A_-(k) = \sin^2\frac{\theta_k}{2}$$

用倍角公式 cos²(x/2) = (1+cos x)/2、sin²(x/2) = (1−cos x)/2：

$$\boxed{\;w^A_\pm(k) \;=\; \tfrac12\big(1 \pm \cos\theta_k\big) \;=\; \tfrac12\big(1 \pm \hat d_z(k)\big)\;}\qquad(\star)$$

**——二能级一般形式**。Estake–Roy 对 Kitaev、长程 SSH、QWZ 逐模型推出的 π(1 ± sin θ̃)、π(1 ± cos Θ) 全是 (★) 换参考轴的特例。

**物理解读**：w^A_±(k) = 上/下带粒子落在子格 A 上的份额 = 赝自旋的 z 投影（子格极化）。强度只含 d̂ 的**方向** θ_k；长度 |d| 与平移 d₀ 完全不出现。

**推论（分辨是前提）**：定义能带投影算符 P_±(k) ≡ |u_±⟩⟨u_±| = ½(𝟙 ± d̂·σ)（由 (d̂·σ)² = 𝟙 知 d̂·σ 本征值为 ±1，此式即其谱投影）。两个子格的权重相加：

$$w^A_\pm + w^B_\pm = \langle A|P_\pm|A\rangle + \langle B|P_\pm|B\rangle = \mathrm{Tr}\,P_\pm = 1$$

（Tr：矩阵迹；正交基上对角元求和 = 取迹。）——**不分辨内态时每带权重恒为 1，无任何信息**。拓扑信号只活在"分辨内态"的强度里。

### 1.4 同族第二强度：Bragg 谱——φ 进入强度的唯一入口

为什么必须带上它：(★) 里 **φ 完全不出现**（强度只看纬度 cos θ），而绕数（§2.1）恰恰由 φ 定义。同族的另一个强度型探针——Bragg 谱——是 φ 唯一进入强度的地方，必须一起算。

**Bragg 探针**：两束光耦合系统总密度，交付一份动量 q ≡ k − k₀（k₀：初态动量；q：转移动量；k：末态动量）与一份转移能量 ω。初态：粒子全部占据下带 k₀（玻色凝聚或单粒子）。末态：动量 k 的上带（带间线）或下带（带内线）。

**跃迁强度仍是交叠模方**（微扰论标准结果：跃迁概率 = 初末态交叠的模方，与 §1.1 同一物理）：

$$w^S_\pm(k_0,k) \;\equiv\; \big|\langle u_\pm(k)\,|\,u_-(k_0)\rangle\big|^2$$

（上标 S 标记"散射/Bragg"；u_−(k₀)：初态——下带 k₀；u_±(k)：末态。）

**推导（三行）**：

第一步（初态赝自旋）：|u_−(k₀)⟩ 是 d̂(k₀)·σ 本征值 −1 的态——赝自旋**反平行**于 d̂(k₀)：

$$\langle u_-(k_0)|\,\boldsymbol\sigma\,|u_-(k_0)\rangle = -\hat{\mathbf d}(k_0)$$

[用 Tr σ_a = 0、Tr σ_a σ_b = 2δ_ab（δ_ab：a = b 时为 1、否则为 0 的记号）算 Tr(σ_a P_−) 即得。]

第二步（把末态投影 P_±(k) 夹进交叠）：

$$w^S_\pm(k_0,k) = \langle u_-(k_0)|\,P_\pm(k)\,|u_-(k_0)\rangle = \tfrac12\Big[1 \mp \hat{\mathbf d}(k)\cdot\hat{\mathbf d}(k_0)\Big]$$

第三步（命名夹角）：定义 d̂(k₀) 与 d̂(k) 的**夹角** Θ(k₀,k) ∈ [0, π]：cos Θ ≡ d̂(k₀)·d̂(k)。得

$$\boxed{\;w^S_+(k_0,k) = \tfrac12(1-\cos\Theta),\qquad w^S_-(k_0,k) = \tfrac12(1+\cos\Theta)\;}\qquad(\star\star)$$

（带间 = sin²(Θ/2)、带内 = cos²(Θ/2)——又一次倍角公式。）求和规则 w^S_+ + w^S_− = 1：被搬的粒子要么换带、要么不换，无其他出路。

**球坐标展开（φ 的唯一入口）**：两个单位矢量的点积在球坐标下是

$$\cos\Theta = \cos\theta_{k_0}\cos\theta_k + \sin\theta_{k_0}\sin\theta_k\,\cos\Delta\varphi(k,k_0),\qquad \Delta\varphi(k,k_0) \equiv \phi_k - \phi_{k_0}$$

方位角差**只以 cos Δφ 进入**，且带系数 sin θ_{k₀} sin θ_k（"通道增益"）：初、末两点都离开 z 轴，φ 的通道才开着；任何一端落在极轴上（θ = 0 或 π），增益为零、通道关闭。

### 1.5 第一部分小结：一切强度 = ½(1 ± cos 某个角)

| 强度 | 公式 | 在比较"什么与什么" |
|---|---|---|
| 谱函数 w^A_±(k) | ½(1 ± cos θ_k) | 轨迹点 d̂(k) vs **钉死的外部 z 轴** |
| Bragg w^S_±(k₀,k) | ½(1 ∓ cos Θ) | 轨迹点 d̂(k) vs **轨迹上另一点 d̂(k₀)** |

两个探针只差一件事：参考物是钉死的轴、还是轨迹自身。共同点决定第二部分的一切：

- 强度里只有**夹角的余弦**——极角 θ_k，或含 cos Δφ 的点积；
- **φ 本身（带符号的相位信息）从未出现**——θ 是"纬度"，不分辨东经西经。

（δ ≠ 0 时这套形式只有一处被改——方位通道整体移相 qδ、纬度通道不动——见 §1.6。）

### 1.6 修正：δ ≠ 0——形状因子把参考矢量绕 z 轴转过 qδ

§1.4 的推导默认总密度算符不带子格相位（两个子格在原胞内重合）。真实晶格中两个子格一般错开一段位移 δ（子格 B 相对 A 的原胞内位移；晶格常数 a = 1，物理单位为 δ/a——δ 是设计期固定的样品几何参数）。总密度的动量空间算符带上**子格形状因子**：

$$\hat\rho_q=\sum_k\hat{\boldsymbol\psi}_{k+q}^\dagger\,F(q)\,\hat{\boldsymbol\psi}_k,\qquad
F(q)=\begin{pmatrix}1&0\\0&e^{iq\delta}\end{pmatrix},\qquad
\hat{\boldsymbol\psi}_k=(\hat c_{k,A},\,\hat c_{k,B})^T$$

——探针依旧不区分子格（耦合的仍是总密度），但 B 分量带上推迟相位 $e^{iq\delta}$。δ = 0 时 $F=\mathbb 1$，逐字恢复 §1.4。为什么必须算它：真实晶格 δ ≠ 0 是常态（δ = 0 是理想化极限），而它恰好划出第一部分小结与第二部分符号 no-go 的**精确边界**。要算的量（q ≡ k − k₀ 同 §1.4）：

$$w^S_\pm(k_0,k;\delta)\equiv\big|\langle u_\pm(k)|\,F(q)\,|u_-(k_0)\rangle\big|^2$$

**第一步（形状因子的唯一物理内容：绕 z 轴的旋转）**。记 β ≡ qδ。直乘验证恒等式

$$F(q)=e^{i\beta/2}\,e^{-i(\beta/2)\sigma_z}\qquad\big(\text{右端}=\mathrm{diag}(e^{i\beta/2}e^{-i\beta/2},\ e^{i\beta/2}e^{i\beta/2})=\mathrm{diag}(1,\,e^{i\beta})\ \checkmark\big)$$

第一个因子是**整体相位**——取模方时消失；剩下的是**内态空间中的旋转算符**

$$U(\beta)\equiv e^{-i(\beta/2)\sigma_z}=\mathrm{diag}\big(e^{-i\beta/2},\ e^{+i\beta/2}\big)$$

（给两个内态分量配一对相反的相位）。它的几何作用用 §1.2 的显式本征矢一步读出——乘到 |u_+(k)⟩ 上：

$$U(\beta)\,|u_+(k)\rangle
=\begin{pmatrix}e^{-i\beta/2}\cos\frac{\theta_k}{2}\\[4pt] e^{+i\beta/2}\,e^{i\phi_k}\sin\frac{\theta_k}{2}\end{pmatrix}
=e^{-i\beta/2}\begin{pmatrix}\cos\frac{\theta_k}{2}\\[4pt] e^{i(\phi_k+\beta)}\sin\frac{\theta_k}{2}\end{pmatrix}$$

——**极角 θ_k 不动、方位角 φ_k → φ_k + β**（只差一个无关紧要的整体相位）。同一个 U 作用到正交伙伴上：U 幺正保正交，而二维空间中与"赝自旋沿 $+R_z(\beta)\hat{\mathbf d}(k)$"本征态正交的归一态必是"沿 $-R_z(\beta)\hat{\mathbf d}(k)$"的本征态。故得到一行引理（R_z(β)：三维矢量绕 z 轴转角 β 的旋转——方位角移 +β、极角与 z 分量不动）：

$$U(\beta)\ \text{把"赝自旋沿}\ \pm\hat{\mathbf d}\text{"的态送到"沿}\ \pm R_z(\beta)\hat{\mathbf d}\text{"的态（各差一个相位）}$$

**第二步（旋转后的参考 + 投影算符路线）**。丢掉整体相位，跃迁重叠 = 末态与**被旋转的初态**的重叠：$|\tilde v(k_0)\rangle\equiv U(\beta)|u_-(k_0)\rangle$（归一，因 U 幺正；赝自旋 $= -R_z(\beta)\hat{\mathbf d}(k_0)$，由 §1.4 第一步 + 上述引理）。于是与 §1.4 第二步**完全相同的代数**：

$$w^S_\pm(k_0,k;\delta)=\big|\langle u_\pm(k)|\tilde v(k_0)\rangle\big|^2
=\langle\tilde v|\,P_\pm(k)\,|\tilde v\rangle
=\tfrac12\Big[1\mp\hat{\mathbf d}(k)\cdot R_z(q\delta)\,\hat{\mathbf d}(k_0)\Big]$$

命名 $\cos\Theta_\delta(k_0,k)\equiv\hat{\mathbf d}(k)\cdot R_z(q\delta)\,\hat{\mathbf d}(k_0)$（"被弦修正的夹角"）：

$$\boxed{\;w^S_\pm(k_0,k;\delta)=\tfrac12\big(1\mp\cos\Theta_\delta\big)\;}\qquad
\delta=0:\ R_z(0)=\mathbb 1\ \text{逐字恢复}\ (\star\star)$$

求和规则 $w^S_+ + w^S_- = 1$ 照旧（F 幺正 ⟹ 模方和不变；或两条式直接相加）。**唯一被改的**：参考矢量 $\hat{\mathbf d}(k_0)$ 先绕 z 轴（被分辨内态的轴！）转过 qδ，再进入内积。

**球坐标展开——只有一项被改**。R_z 只动方位角（φ_{k₀} → φ_{k₀} + qδ，θ_{k₀} 与 ẑ 分量不动），代入点积：

$$\cos\Theta_\delta=\cos\theta_{k_0}\cos\theta_k+\sin\theta_{k_0}\sin\theta_k\,\cos\big(\Delta\varphi(k,k_0)-q\delta\big)$$

与 §1.4 的 cos Θ 逐项对比：**纬度通道 $\cos\theta_{k_0}\cos\theta_k$ 纹丝不动；方位通道整体移相 −qδ**（通道增益 $\sin\theta_{k_0}\sin\theta_k$ 原样保留）。δ 旋钮开在、且只开在 §1.4 末尾"φ 的唯一通道"上——恰好是带绕数信息的那条通道（§2.1）、也是极点处关闭的那条通道。等效读法（一行，旋转保点积）：$\hat{\mathbf d}(k)\cdot R_z(\beta)\hat{\mathbf d}(k_0)=R_z(-\beta)\hat{\mathbf d}(k)\cdot\hat{\mathbf d}(k_0)$——"弦在参考上"与"整条轨迹被反向均匀旋转、参考不动"是同一数据。

**三个推论**（c4 / c8 / c13 核验）：

1. **镜像把 δ 映到 −δ——δ = 0 是符号 no-go 的精确边界**。§2.2 的镜像变形 Δφ → −Δφ，代入上式恰好抵消移相：$w(M_PS;\delta)=w(S;-\delta)$ 逐 (k₀, k)（c4：0.00）。两个特例：(i) δ = 0：镜像是数据的**精确对称**——§2.2 no-go 的适用范围正是 δ = 0（或任何 ±δ 对称的协议）；(ii) δ ≠ 0：弦自带一个外部取向（绕 z 转的旋向），破坏镜像简并，原则上符号进入强度——线性缠绕族 $\psi_k=Wk$ 时 $w_+\propto\tfrac12[1-\cos((W-\delta)(k-k_0))]$，数据由 $|W-\delta|$ 决定，δ 扫描的 V 形顶点落在 δ = W（含符号）。诚实限制：δ 是设计期固定的几何参数；自然对称晶格 δ = a/2 恰为擦除值（$|W-\tfrac12|=|W\oplus1-\tfrac12|$，整数对 $(W, W\oplus1)$ 数据全同，c8）。
2. **极点参考对一切 δ 惰性**。参考在极点（θ_{k₀} = 0 或 π，即 $\hat{\mathbf d}(k_0)=\pm\hat z$）时 $R_z(\beta)\,\pm\hat z=\pm\hat z$（转轴上的不动点），故 $\cos\Theta_\delta=\pm\hat d_z(k)$ 与 δ **无关**、逐点等于 SPSF 图案——§2.3 失效清单第 3 条的极点退化从"δ = 0 的 Bragg"加强为"一切 δ 的 Bragg"（c13：δ = 0.11/0.37/0.73，机器精度）。几何：δ 旋钮沿纬圈方向拧，而极点的纬圈缩成一点。
3. **手性圆上：对跖条件移相 qδ**。§2.3 判据一在弦下变为 $w_+=\tfrac12\big(1-\cos(\psi_k-\psi_{k_0}-q\delta)\big)$：满转移 ⟺ $\psi_k=\psi_{k_0}+q\delta+\pi$。δ = 0 时拓扑相（W ≠ 0）对一切 k₀ 有解（判据二）；δ ≠ 0 时有效净缠绕变为 $W-\delta$（ψ − qδ 沿 BZ 的净变化 $2\pi(W-\delta)$），且谱对 q 不再周期（$e^{i(q+G)\delta}\neq e^{iq\delta}$）——满转移与否依赖扫描窗口，δ → a/2 处拓扑相的满转移被擦到 ½（c8）。判据四（SPSF 侧）完全不受影响——弦不动纬度通道。

## 第二部分　从绕数的定义到强度形式隐含的信息

### 2.1 绕数的定义（以及它何时值得读）

**定义**：绕 z 轴（被分辨内态轴）的绕数

$$W \;\equiv\; \frac{1}{2\pi}\oint_{\mathrm{BZ}} dk\,\,\partial_k\phi(k)$$

- ∂_k φ ≡ dφ/dk：方位角随 k 的变化率；∮_BZ dk：k 沿 BZ 从 −π 积到 π 一整圈；
- 物理意义：k 走完一圈，d̂(k) 绕 z 轴**净转过的整圈数**（带符号；定向约定：从 +z 俯视逆时针为正，W > 0——约定反了全体变号，不影响结论）；
- **W 是整数**：BZ 首尾相接、轨迹闭合，φ 必须回到出发值——只能差 2π 的整数倍（转一整圈 = 2π）；
- **良定义条件**：轨迹不穿过 z 轴（θ = 0 或 π 处 φ 无定义）；
- 等价算法（判据要用）：把垂直于 z 的两个分量组成复数 z(k) ≡ d_x(k) + i d_y(k)，则 W = k 扫一圈时 z(k) 绕复平面原点的圈数。

**W 何时值得读（一句话物理）**：一般系统里，保持能隙开着、连续形变 d̂(k)，可以让轨迹绕开或穿过 z 轴，W 跳 ±1——它只是当前轨迹的一个读数，不是系统的稳定性质。

**手性系统**例外（恰好是 SSH / Kitaev 一族）。手性对称的物理内容：存在一个内态指标，使两个内态**只有交叉耦合、没有自耦合**（SSH：子格 A、B 之间有跳跃，A–A、B–B 之间没有）。公式：{H, Γ} = 0，即 HΓ + ΓH = 0，其中 Γ = n̂_Γ·σ 是该指标的算符（n̂_Γ：某单位矢量；Γ² = 𝟙）。把 Pauli 展开代入得

$$\hat{\mathbf d}(k)\cdot\hat n_\Gamma \equiv 0\ \ \forall k \qquad\Longrightarrow\qquad \text{轨迹整条钉死在垂直 } \hat n_\Gamma \text{、过球心的大圆上}$$

（大圆：球面上过球心的圆。）在此圆上读绕数（轴取 n̂_Γ）：W 要变，轨迹必须穿过 n̂_Γ 轴（球面上 ±n̂_Γ 两点）；而圆与该轴在球面上**不相交**（轴垂直穿圆心而过）。要相遇只剩一条路：d 的平行与垂直分量同时归零，即 **|d| = 0、能隙闭合**。所以只要能隙不闭、手性不破，W 冻结——**拓扑保护**。此后"绕数"默认指绕 n̂_Γ 的 W。

（两个标准构型——SSH：n̂_Γ = ẑ，圆 = 赤道，d_z ≡ 0；Kitaev：n̂_Γ = x̂，圆 = y–z 大圆，d_x ≡ 0——§2.4 一张表。）

### 2.2 比较第一步：W 的符号为什么结构性读不出

绕数带**符号**（净缠绕有方向）。检查 §1.5 的两个形式里 φ 怎么出现：

- 谱函数 (★)：只有 cos θ_k——**φ 根本不在场**；
- Bragg (★★)：φ 只以 cos Δφ 出现。

而 **cos 是偶函数：cos(Δφ) = cos(−Δφ)**。

**镜像构造**（把这条偶性变成两个真实物理系统）：定义第二个系统，把轨迹关于含 z 轴的 x–z 平面照一面镜子：

$$\mathbf d'(k) = \big(d_x(k),\; -d_y(k),\; d_z(k)\big) \qquad\Longleftrightarrow\qquad \phi(k)\to-\phi(k)$$

物理实现：把 H 取复共轭（σ_y 是纯虚矩阵，其余两个是实的），等价于把所有含 σ_y 的项整体变号（例如把某个复跃迁振幅取共轭）。d′ 仍是实矢量场，H′ = d′·σ 仍是合法厄米哈密顿量，能谱、带序与原系统全同——**真实存在的另一个系统**。

逐项比较两者的 δ = 0 强度数据：

1. 谱函数：cos θ_k = d̂_z(k) 在镜像下不变（镜子含 z 轴，不动 z 分量）⟹ w^A_±(k) **逐点全同**；
2. Bragg：cos θ_{k₀} cos θ_k 不变；cos Δφ → cos(−Δφ) = cos Δφ 不变 ⟹ w^S_±(k₀, k) **逐点全同**（对一切 k₀、k）；
3. 绕数：φ → −φ ⟹ ∂_k φ → −∂_k φ ⟹ **W′ = −W**。

**（更一般的一行论证）**：H′ = H 的复共轭，其本征态 = 原系统本征态的复共轭，故**任何**两个态的交叠只被复共轭——模方不变。所以不止这两个探针：一切"交叠模方"型数据（任意初末态、任意组合）全部逐项相同（c2/c3）。

**结论一（符号结构性不可读）**：存在两个真实的物理系统，δ = 0 强度数据完全相同而 W 相差一个符号。因此 W 的符号**不在强度数据里**——任何探针、任何组合、任何后处理都读不出。这不是"难测"，是"不在"：强度按定义是模方，模方按定义丢相位，而符号恰好住在被丢掉的那部分里。

**同时检查 |W|**：|W′| = |−W| = |W|——偶性论证**不挡 |W|**，|W| 原则上在数据可及范围内。能否真读出、要什么条件——下一步。

（适用范围：此论证不用手性、不用任何对称性假设，对一切带隙二能级系统成立；数值核验含非手性随机模型。）

### 2.3 比较第二步：$|W|$ 何时可读（手性圆上四个判据）

四个判据分两层回答两个问题：**判据一**是一条双向恒等式（读数器），把数据特征翻译成轨迹的几何事实；**判据二**在它之上回答 **$W$ 是否非零**；**判据三、四**在它之上数出 **$|W|$ 的数值**（Bragg 侧、谱函数侧各一条计数）。每个判据依次给出：数据特征、读出、前提、方向。

**设置（手性大圆上的记号）**。轨迹整条躺在垂直 $\hat n_\Gamma$、过球心的大圆上（§2.1——$|W|$ 值得读的地方）。给圆选定一个绕行方向为正，记：

- $\psi_k$：$\hat{\mathbf d}(k)$ 在圆上的**带符号位置角**（SSH 构型：$\psi=\phi$，绕 $\hat z$；Kitaev 构型：$\psi=\arg(d_z+i\,d_y)$，绕 $\hat x$）；
- 绕数 $=$ 圆上角的净变化：$W=\dfrac{1}{2\pi}\displaystyle\oint_{\mathrm{BZ}}dk\,\partial_k\psi_k$（§2.1 的定义，轴取 $\hat n_\Gamma$）；
- 圆上任意两点的夹角 $=$ 带符号角差：$\hat{\mathbf d}(\psi)\cdot\hat{\mathbf d}(\psi')=\cos(\psi-\psi')$（把圆参数化为 $\hat{\mathbf d}(\psi)=\cos\psi\,\hat{\mathbf e}_1+\sin\psi\,\hat{\mathbf e}_2$，$\hat{\mathbf e}_1$、$\hat{\mathbf e}_2$ 为圆平面内一对正交单位矢量，点积展开即得）。

两个强度在圆上的形式（$(\star)$、$(\star\star)$ 代入，此后只用这两条）：

- **Bragg**（参考 $=$ 轨迹上另一点）：$w^S_\pm(k_0,k)=\tfrac12\big(1\mp\cos(\psi_k-\psi_{k_0})\big)$；
- **谱函数**（参考 $=$ 钉死的 $\hat z$ 轴）：把 $\hat z$ 分解为圆平面内分量 $\hat z_\parallel$ 与垂直分量 $\hat z_\perp$，记 $\rho\triangleq\|\hat z_\parallel\|=\sin\beta$（$\beta$：$\hat z$ 与圆平面法向 $\hat n_\Gamma$ 的夹角，度量 $\hat z$ "躺进"圆平面的程度）、$\psi_z$ 为 $\hat z_\parallel$ 在圆上的位置角（$\rho=0$ 时 $\psi_z$ 无关紧要）。因 $\hat z_\perp$ 垂直于圆平面、点积为零，$\hat d_z(k)=\hat z\cdot\hat{\mathbf d}(k)=\rho\cos(\psi_k-\psi_z)$，故

$$w^A_\pm(k)=\tfrac12\big(1\pm\rho\,\cos(\psi_k-\psi_z)\big)$$

——移位 $\psi_z$、折减 $\rho$ 的余弦。两个形式里只剩"圆上两角之差"的余弦，而绕数正是角的净变化——四个判据全部由此读出。

**判据一（读数器：满转移 $\iff$ 对跖命中；无前提）**。数据特征：带间强度在单个 $k$ 达到 1——全部粒子搬进上带、带内线熄灭（下称**满转移**）。推导一行：$w^S_+(k_0,k)=1\iff\cos(\psi_k-\psi_{k_0})=-1\iff\psi_k=\psi_{k_0}+\pi\ (\mathrm{mod}\ 2\pi)$（相差 $2\pi$ 整数倍视为同一角）$\iff\hat{\mathbf d}(k)=-\hat{\mathbf d}(k_0)$——初态点的**对跖点**（球面直径的另一端）。记 $W_{\max}(k_0)\triangleq\max_k w^S_+(k_0,k)$（初态钉在 $k_0$ 时带间强度的最大值），则

$$W_{\max}(k_0)=1\iff-\hat{\mathbf d}(k_0)\in\mathrm{image}\,\hat{\mathbf d}$$

（$\mathrm{image}\,\hat{\mathbf d}$：轨迹扫过的全部点。）双向恒等，供后三个判据调用。

**判据二（$W\neq0\Rightarrow$ 处处满转移；单向）**。数据特征：满转移对**一切**初态 $k_0$ 成立（**处处满转移**）。推导：设 $W\neq0$，$\psi$ 走完 BZ 的净变化为 $2\pi W\neq0$。若像漏掉一点，则因像是闭集（BZ 有界闭、$\psi$ 连续；闭集的补集是开集），漏掉的点周围有一段开弧整体不在像内，$\psi$ 的全部取值便落在其余长度 $<2\pi$ 的闭弧内，可全程不跨 $2\pi$ 地连续取值、走完一圈回到出发值——净变化只能为 0，矛盾。故像盖满整圆、一切对跖皆在像内：

$$W\neq0\ \Longrightarrow\ W_{\max}(k_0)=1\qquad\forall k_0\qquad(\mathrm{c5})$$

方向（本判据只有单向可用）：**可靠的一向是逆否**——只要有一个 $k_0$ 满转移失败（$W_{\max}(k_0)<1$），即可断定 $W=0$（一票否决）；**反向不可用**——处处满转移推不出 $W\neq0$（"双程"假阳性，清单第 1 条）。一句话：处处满转移是 $W\neq0$ 的**必要条件**，不是充分条件。

**判据三（带内线熄灭次数 $=|W|$；Bragg 侧；前提：$\psi$ 单调、参考避开极点）**。数据特征：**带内线熄灭的次数**。推导：设 $\psi(k)$ 单调（一路朝同一方向净绕 $|W|$ 整圈），则对跖角 $\psi_{k_0}+\pi$（初态对跖点的位置角）每圈恰被命中一次、共 $|W|$ 次。操作形式取同一张谱里带间线与带内线之比（$R$；免绝对定标——整体校准对两条线乘同一因子，比值不变）：

$$R(k)\triangleq\frac{w^S_+(k_0,k)}{w^S_-(k_0,k)}=\tan^2\frac{\psi_k-\psi_{k_0}}{2}$$

$R$ 恰在对跖点发散（$w^S_-\to0$，带内线熄灭），故**带内线熄灭次数 $=|W|$**（c5）。两个前提各挡一类失效：$\psi$ 单调挡"一去一回"（清单第 1 条）；参考避开极点保证 Bragg 的 $\Delta\varphi$ 通道开着（清单第 3 条）。

**判据四（基线穿越数 $=2|W|$；谱函数侧；前提：$\psi$ 单调、$\rho\neq0$）**。数据特征：**基线穿越次数**——$w^A_\pm(k)$ 跨过基线 $\tfrac12$（即 $\hat d_z=0$；Estake–Roy 的"A 穿越 $\pi$"是同一件事，他们的强度单位里基线为 $\pi$）。推导：$\rho\neq0$ 时 $\hat d_z=0\iff\psi_k=\psi_z\pm\tfrac{\pi}{2}$，圆上每圈恰 2 个点；$\psi$ 单调绕 $|W|$ 圈，故**基线穿越数 $=2|W|$**（c9）。$\rho=0$（$\hat z$ 垂直于圆平面）时 $w^A_\pm\equiv\tfrac12$ 严格平、一次也不穿越——**判据四整条失效**（SSH 构型正是如此：被分辨轴与手性轴重合，手性强迫 $d_z\equiv0$）。

**四判据一览**：

| 判据 | 数据特征 | 读出 | 前提 |
|---|---|---|---|
| 一（读数器） | 单点满转移 | 对跖在像内 | 无（恒等式） |
| 二 | 是否处处满转移 | $W\neq0$ 的必要条件（一处失败 $\Rightarrow W=0$） | 手性圆 |
| 三 | 带内线熄灭次数 | $|W|$ | $\psi$ 单调；$k_0$ 避开极点 |
| 四 | 基线穿越次数 | $2|W|$ | $\psi$ 单调；$\rho\neq0$ |

**失效清单（判据何时读错）**：

1. **盖满整圆 $\not\Rightarrow W\neq0$（"双程"）**：轨迹一去一回仍可盖满整圆（净绕 0）。反例：$W=0$ 而 $W_{\max}\equiv1$、带内线熄灭 2 次——按判据三读作 $|W|=2$，错（c6）。判据二的正向、判据三的计数同时被它骗；判据三的单调前提正是用来挡这一类。
2. **单点满转移 $\not\Rightarrow$ 非平庸（"擦过"）**：平庸弧经精细调节可恰好擦过对跖——单点事件，测度为零。
3. **极点参考关闭 Bragg 通道**：$\Delta\varphi$ 通道带增益 $\sin\theta_{k_0}\sin\theta_k$（§1.4）。初态 $k_0$ 落在极点（$\theta_{k_0}=0$ 或 $\pi$；Kitaev 构型的圆过两极，确会发生——SSH 构型的赤道不过极点，自动安全）时增益为零、通道在参考端关闭，且 Bragg 逐点退化为谱函数——取 $\psi_{k_0}=\pi$（$\hat{\mathbf d}(k_0)=-\hat z$，初态赝自旋 $=-\hat{\mathbf d}(k_0)=+\hat z=\lvert A\rangle$ 字面成立）：

$$w^S_\pm(k_0,k)=\tfrac12\big(1\mp\cos(\psi_k-\pi)\big)=\tfrac12\big(1\pm\cos\psi_k\big)=w^A_\pm(k)$$

逐点相同（c7）——可动参考撞上被钉死的参考，**继承谱函数的一切假阳性**（含第 4 条）。判据三要求参考避开极点、判据四要求 $\rho\neq0$，正是保证各自通道开着。
4. **谱函数假阳性**：非单调轨迹同样给出基线穿越 2 次（回折、折叠两例：$W=0$、穿越数 2，误读 $|W|=1$；c9/c10——其中折叠例 $W_{\max}(k_0)<1$ 对一切 $k_0$ 严格成立，可被一般参考的 Bragg 揭穿）。

**端到端最小例（c11）**：一对轨迹——T（$\psi=k$：单调整圈，$W=1$）与 R（$\psi$ 一去一回，$W=0$）。谱函数逐点全同（两者的 $\hat d_z(k)=\cos k$ 同为 $k$ 的偶函数）、基线穿越同 2 次、极点参考的 Bragg 同骗；一般参考 $k_0=-\pi/2$ 的 Bragg 把两者分开：$W_{\max}=1.000$ vs $0.500$（回折只盖半圈，对跖不在像内）。整条链（余弦形式 → 镜像 → 判据 → 揭穿）在最小对上一次走完。

**推论（$k_0$ 钉死为基态动量：判据收缩）**。§1.4 的初态设定是"粒子全部占据下带 $k_0$（玻色凝聚或单粒子）"——真实实验里 $k_0$ 不是自由旋钮，由基态决定：$k_0$ 固定在下带底，即 $\lvert d(k)\rvert$ 最大处（$E_-=-\lvert d\rvert$）。钉死后逐条清点判据。

**与"多 $k_0$"绑定的只有两件事**，钉死后消失：判据二的**正向**（"处处满转移"须遍历一切 $k_0$）；**换参考揭穿**（c11 揭穿 R 用的 $k_0=-\pi/2$）。其余照旧——它们本来就单点工作：判据一（恒等式）；判据二的**否决向**（$W_{\max}(k_0)<1\Rightarrow W=0$——定理对每个 $k_0$ 单独成立，单点照用）；判据三（计数本是固定 $k_0$ 的读数）；判据四（谱函数侧，与 $k_0$ 无关）。

于是只剩一个分岔：**基态 $k_0$ 是否极点**（$\theta_{k_0}=0$ 或 $\pi$——通道增益 $\sin\theta_{k_0}=0$、参考端关闭，失效清单第 3 条）。落点由构型与参数决定：

| 基态 $k_0$ 落点 | 判据一 | 判据二 | 判据三 | 判据四 | 正向判 $W\neq0$ |
|---|---|---|---|---|---|
| SSH 型：手性强迫轨迹整条在赤道，基态必在赤道、非极点，通道开 | 可用 | 仅否决向 | 可用（极点前提自动满足；需 $\psi$ 单调） | 死（$\rho=0$） | 三的计数 |
| Kitaev 型，能带底使 $\hat{\mathbf d}(k_0)=\pm\hat z$（标准族 $d_y\propto\sin k$：$k=0,\pi$ 处 $d_y=0$，$d_z$ 幅度主导时底在此） | 退化为谱函数 | 退化为谱函数 | 退化为谱函数 | 可用（$\rho=1$；需 $\psi$ 单调） | 四的计数 |
| Kitaev 型，能带底在内部点（$\hat{\mathbf d}(k_0)$ 在圆中部；$d_y$ 幅度主导时底在此） | 可用 | 仅否决向 | 可用（需 $\psi$ 单调） | 可用（$\rho=1$；需单调） | 三或四的计数 |

三行各一条注解：

- **SSH 行——钉死几乎零损失**：拓扑相轨迹盖满整圆，对跖必在像内、单调时计数恰 $1$；平庸相像是不含对跖的小弧，计数 $0$、否决一票定 $W=0$——基态这一个 $k_0$ 就分开两相。
- **Kitaev 极点行——正中 c7 退化**：三条 Bragg 判据照写，读数却全落在**同一张谱函数谱**上，零独立信息——否决向退化为"$w^A_+$ 从未达 1（轨迹缺对跖极点）$\Rightarrow W=0$"（折叠例如此被抓，c10）；计数退化为"$w^A_-$ 过零 = 过对跖极点次数"（与判据四同谱同源，非独立检验）。实际只剩判据四；假阳性中的**回折、双程**（c11/c6）在这张谱内不可揭穿（R 与 T 谱函数逐点全同）——换参考的逃生门被钉死关上。
- **Kitaev 内部行**：基态恰是一般参考，四条全活，钉死代价最小。

**两个共同代价**：其一，正向判 $W\neq0$ 只剩"单调计数 $\ge1$"一条路（判据二正向已失）；其二，单点否决变成**抽签**——$W=0$ 的轨迹若恰好也经过基态 $k_0$ 的对跖，否决沉默（如 R 的像含两极：任一极点参考的对跖都在像内），且再无第二个参考可换。

一句话：基态把 $k_0$ 钉死在极点时，Bragg 在 $\delta=0$ 下的唯一结构优势（可动参考，§1.5）被基态选择整条没收——判据清单收缩为"谱函数判据 + $\psi$ 单调前提"。

### 2.4 两个标准构型（同一套公式，两个 β）

| | 构型 A：SSH 型 | 构型 B：Kitaev 型 |
|---|---|---|
| 手性轴 n̂_Γ（= 绕数保护轴） | ẑ（**=** 被分辨轴） | x̂（**⊥** 被分辨轴） |
| 手性圆 | 赤道（d_z ≡ 0） | y–z 大圆（d_x ≡ 0，**过两极**） |
| ρ = sin β | 0 | 1 |
| 谱函数 | ½ 严格平——**全盲** | ½(1 ± cos ψ_k) 满对比 |
| Bragg | ½(1 ∓ cos Δφ)——φ 的唯一入口 | ½(1 ∓ cos Δψ) |
| 极点退化 | 圆不过极点，无 | k₀ 在极点时 Bragg ≡ 谱函数（§2.3 第 3 条） |

统一读法：谱函数 = "参考被钉死、且振幅折减 ρ 的 Bragg"；β（z 轴与手性圆平面的夹角）取两个特殊值，把两个著名模型缝进同一套公式。

### 2.5 总表：二能级一般形式隐含哪些绕数信息

| 绕数信息 | 在不在 δ = 0 强度里 | 依据 / 条件 |
|---|---|---|
| **W 的符号** | **不在（结构性）** | 镜像对数据逐项全同而 W′ = −W（§2.2）；一切交叠模方型数据中招 |
| **W 是否非零** | **在** | 判据二：W ≠ 0 ⟹ 处处满转移；逆命题假（双程、擦过；§2.3 清单） |
| **\|W\| 的数值** | **在** | 判据三：带内线熄灭次数 = \|W\|；判据四：基线穿越数 = 2\|W\|；都需 ψ 单调 + 通道开（参考避开极点 / ρ ≠ 0） |
| 谱函数单枪匹马 | 不够 | (★) 不含 φ；SSH 构型全盲（ρ = 0）；假阳性须靠一般参考的 Bragg 揭穿 |

一句话：**一般形式 ½(1 ± cos) 是"夹角的余弦"——它保住了 |W|（单调、通道开的条件下可数出来），而 cos 的偶性把符号那一比特挡在数据之外**；符号住在交叠的**相位**里（那是另一条线：带内 Bragg 矩阵元的回路相位）。
